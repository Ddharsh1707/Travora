# Place coordinates

`supabase/migrations/20261107000410..430_locations_*.sql` are generated by `make_seed.py` from public datasets. Coordinates are copied from them and never estimated.

| File | Source | Licence |
| --- | --- | --- |
| airports | [OurAirports](https://ourairports.com/data/) `airports.csv`: airports with an IATA code and scheduled service, plus every IATA-coded airport in India | Public domain |
| stations | [datameet/railways](https://github.com/datameet/railways) `stations.json`: Indian Railways stations with coordinates | ODbL |
| cities | [GeoNames](https://www.geonames.org/) cities1000, via [lutangar/cities.json](https://github.com/lutangar/cities.json): towns and cities in India | CC BY 4.0 |

To regenerate the seed files, download the three files into one folder, then run:

    python3 scripts/locations/make_seed.py <that folder> supabase/migrations
